# FPTU DMS Vision — Evidence

Mỗi Evidence ID chỉ có một thư mục riêng từ `E-01` đến `E-42`.

Nhóm chỉ cần đưa trực tiếp log, ảnh, video, CSV, JSON, PDF hoặc tài liệu liên quan vào đúng thư mục Evidence ID tương ứng. Không bắt buộc phải tạo thêm thư mục con.

Ví dụ:

```text
E-04/
├── golden_event.jsonl
├── backend_log.txt
├── dashboard.png
└── demo.mp4
```

Tra cứu ý nghĩa của từng Evidence ID trong `EVIDENCE_INDEX.md`.

File `.gitkeep` trong mỗi thư mục chỉ dùng để giữ thư mục khi đưa lên GitHub; có thể giữ nguyên hoặc xóa sau khi đã thêm evidence thực tế.
